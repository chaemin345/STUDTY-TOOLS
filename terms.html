STUDTY TOOLS 이용약관

시행일: 운영 개시일에 확정

운영 전 사업자/운영자 정보, 고객 문의 연락처, 환불 정책, 관할 및 준거법을 실제 운영 조건에 맞게 확정하고 법률 검토를 거쳐야 합니다. 이 문서는 개발용 초안입니다.

1. 서비스

STUDTY TOOLS는 과목, 과제, 학습 시간표, 집중 기록 및 선택형 AI 학습 분석 기능을 제공하는 학습 관리 서비스입니다.

2. 이용권 및 결제

Pro 30일 이용권은 결제 승인일부터 30일, Pro 365일 이용권은 결제 승인일부터 365일 동안 제공됩니다. 현재 결제 구조는 자동 갱신이 아닌 일회성 이용권입니다. 이용 기간 만료 후 별도 구매가 없으면 Free 플랜으로 전환됩니다.

3. 환불 및 취소

환불 가능 여부와 계산 방식은 실제 판매자 지위, 관련 법령, 디지털 콘텐츠 제공 개시 여부 및 결제 조건에 맞춰 운영 전에 구체적으로 확정해야 합니다. 이 초안만으로 환불 기준이 확정된 것은 아닙니다.

4. 외부 API

사용자가 연결한 OpenAI, Anthropic, Google Gemini 등 외부 API의 이용료와 제공자 약관은 각 제공자의 정책을 따릅니다. 외부 API 사용으로 발생하는 비용은 해당 API 계정 소유자에게 청구될 수 있습니다.

5. 서비스 변경 및 문의

실제 운영자 정보와 고객 문의 채널을 여기에 기재해야 합니다.
