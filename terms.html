STUDTY TOOLS 이용약관

시행일: 운영 개시일에 확정

운영 전 사업자/운영자 정보, 고객 문의 연락처, 관할 및 준거법을 실제 운영 조건에 맞게 확정하고 법률 검토를 거쳐야 합니다. 이 문서는 개발용 초안입니다.

1. 서비스

STUDTY TOOLS는 과목, 과제, 학습 시간표, 집중 기록 및 선택형 AI 학습 분석 기능을 제공하는 학습 관리 서비스입니다.

2. Pro 기능

현재 유료 플랜의 구매와 결제 기능은 제공하지 않습니다. Pro 권한은 서버에서 확인되는 이용 상태 또는 마스터 계정 권한에 따라 제공됩니다. 향후 유료 결제를 도입할 경우 이용 조건, 가격, 제공 기간 및 적용 시점을 별도 고지하고 이 약관을 개정합니다.

3. 결제 및 환불

현재 STUDTY 내에서 결제를 받거나 환불을 처리하지 않습니다. 향후 결제 기능을 도입할 때에는 관련 법령과 디지털 콘텐츠 제공 조건에 맞춰 결제·취소·환불 정책을 확정해 사전에 고지합니다.

4. 외부 API

사용자가 연결한 OpenAI, Anthropic, Google Gemini 등 외부 API의 이용료와 제공자 약관은 각 제공자의 정책을 따릅니다. 외부 API 사용 비용은 해당 API 계정 소유자에게 청구될 수 있습니다.

5. 서비스 변경 및 문의

실제 운영자 정보와 고객 문의 채널을 여기에 기재해야 합니다.
