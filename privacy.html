STUDTY TOOLS 개인정보 처리방침

시행일: 운영 개시일에 확정

개인정보 처리자, 소재지, 문의처, 보유기간, 국외 이전 및 위탁 현황 등을 실제 사업 구조에 맞춰 확정하고 법률 검토를 거쳐야 합니다. 이 문서는 개발용 초안입니다.

1. 처리 항목

회원 인증을 위해 이메일 주소와 인증 관련 식별자를 처리합니다. 현재 STUDTY는 유료 결제 기능을 제공하지 않으며 카드번호, CVC, 결제 키, 결제 주문정보를 수집하거나 처리하지 않습니다.

2. API 연결 정보

사용자가 입력한 외부 API 키는 서버에서 AES-256-GCM 방식으로 암호화하여 저장합니다. API 키 원문은 브라우저 저장소에 저장하거나 조회 응답으로 반환하지 않습니다. 사용자가 연결한 제공자에게는 해당 API 요청에 필요한 데이터가 전송됩니다.

3. 학습 데이터

기본 학습 데이터는 현재 브라우저 저장소에 저장됩니다. AI 학습 기능을 요청할 때에는 과목, 목표 시험일, 미완료 과제 및 학습 세션 요약이 선택한 AI API 제공자에게 전송될 수 있습니다.

4. 보유 및 파기

회원 계정과 API 연결 정보의 보유기간 및 파기 절차는 실제 운영자의 법적 의무와 서비스 운영 정책에 맞춰 확정해야 합니다.

5. 문의

실제 개인정보 보호 책임자 및 문의 채널을 여기에 기재해야 합니다.
